# 🌟 تطبيق شهد وشذى - تعلم الإنجليزية بالمرح

تطبيق Flutter تعليمي للأطفال، يعلّمهم الحروف الإنجليزية والكلمات ومعانيها بالعربية، عبر بطاقات تفاعلية، نطق صوتي حقيقي، وألعاب (مطابقة كلمات + اختبار)، مع تصميم ملوّن وحركات ممتعة.

## ⚠️ ملاحظة مهمة
تم إعداد هذا المشروع **كملف كود مصدري (Source Code) كامل وجاهز للبناء**، ولم يُبنَ كملف APK جاهز لأن بيئة العمل الحالية لا تحتوي على Flutter SDK ولا اتصال إنترنت لتثبيته وتحميل الحزم. اتبع الخطوات التالية على جهازك لبناء الـ APK وتجربته خلال دقائق.

## 🛠️ خطوات بناء الـ APK

1. **ثبّت Flutter** (إن لم يكن مثبتاً):
   https://docs.flutter.dev/get-started/install

2. تأكد من أن كل شيء جاهز:
   ```
   flutter doctor
   ```

3. من داخل مجلد المشروع `shahd_shaza`، شغّل هذا الأمر **مرة واحدة فقط** لتوليد ملفات منصة أندرويد/iOS الأساسية (المشروع يحتوي فقط على الملفات المخصصة: lib, assets, pubspec, وAndroidManifest المعدّل، وهذا الأمر يكمل الباقي دون أن يمسّ ملفاتك):
   ```
   flutter create .
   ```

4. بعدها نزّل الحزم:
   ```
   flutter pub get
   ```

5. لتجربته مباشرة على جهاز أو محاكي متصل:
   ```
   flutter run
   ```

6. لبناء ملف APK جاهز للتثبيت:
   ```
   flutter build apk --release
   ```
   بعد الانتهاء ستجد الملف هنا:
   ```
   build/app/outputs/flutter-apk/app-release.apk
   ```
   انسخه لهاتفك وثبّته مباشرة (فعّل خيار "مصادر غير معروفة" إن طُلب منك).

## 📁 محتويات المشروع
- `lib/main.dart` — نقطة بداية التطبيق والألوان العامة
- `lib/screens/splash_screen.dart` — شاشة الترحيب
- `lib/screens/home_screen.dart` — القائمة الرئيسية
- `lib/screens/alphabet_screen.dart` — تعلم الحروف مع النطق
- `lib/screens/word_match_game.dart` — لعبة مطابقة الكلمات
- `lib/screens/quiz_game.dart` — لعبة الاختبار
- `lib/screens/developer_screen.dart` — خانة المطور (المهندس حكيم شاكر)
- `lib/data/alphabet_data.dart` — بيانات الحروف/الكلمات/الترجمة
- `assets/images/hakim.png` — صورة المطور

## 📶 ملاحظة حول الإنترنت
أضفنا صلاحية الإنترنت في AndroidManifest لأن حزمة `google_fonts` تُحمّل الخط عند أول تشغيل ثم تخزّنه محلياً (بعدها يعمل التطبيق بدون إنترنت). حزمة `flutter_tts` تستخدم محرك النطق المثبت على جهاز الطفل مباشرة (يعمل غالباً بدون إنترنت).

## 🎨 إضافات يمكنك تطويرها لاحقاً
- إضافة ملفات صوتية حقيقية (mp3) في `assets/audio/` لموسيقى خلفية ومؤثرات، وربطها عبر حزمة `audioplayers` الموجودة مسبقاً في المشروع.
- إضافة لعبة "اسحب وأفلت" لترتيب الحروف لتكوين كلمة.
- إضافة نظام نجوم/شارات تحفيزية باستخدام `shared_preferences` لحفظ تقدم الطفل.
- استبدال الرموز التعبيرية (emoji) بصور رسوم متحركة مخصصة لمزيد من الجاذبية.
